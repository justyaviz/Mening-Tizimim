# Contract Builder v0.8

Contract Builder is based on `docs/marketing-contract-source.md`.

Document structure:
1. Main marketing services agreement — 19 sections.
2. Appendix 1 — project-specific terms.
3. Appendix 2 — party requisites and signatures.

PDF behavior:
- Screen preview shows branded A4 pages.
- PDF button creates a native flowing print document so long text can paginate instead of being clipped.
- The Mening Tizimim letterhead is repeated as a fixed background on printed pages.
- Appendix 1 and Appendix 2 start on new printed pages.
- Contract number and Document ID repeat in the print footer.
